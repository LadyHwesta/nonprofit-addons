# eLearning: Stage Manager

A pure-data module: installing it drops a ready-built course into Odoo's
**eLearning** app.

## What's in the course

The performer roster, setting up stages, building a Run of Show, hard times,
booking status, and printing the sheet for the show. A 4-question quiz at the end.

Screenshots in `static/img/` come from a local test database with sample data.

## Access

Gated (`visibility="members"`, `enroll="invite"`). Everyone with the Entertainment
User right is auto-enrolled.

## Dependencies

`website_slides`, `nonprofit_elearning_theme`, `nonprofit_event_entertainment`.
