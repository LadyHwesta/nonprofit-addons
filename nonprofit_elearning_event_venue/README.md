# eLearning: Vendor Coordinator

A pure-data module: installing it drops a ready-built course,
*"Vendor Coordinator"*, into Odoo's **eLearning** app.

## What's in the course

Booth categories, needs-power and double-wide spots, rows and row/spot
addressing, calibrating the live Vendor Map from three real-world
coordinates, reading the map day-to-day, and the Load-In Manifest /
Vendor Requirements reports. A 4-question quiz at the end.

## Access

Gated (`visibility="members"`, `enroll="invite"`); everyone in
`event.group_event_user` is auto-enrolled via `enroll_group_ids`.

## Dependencies

Only `website_slides` + `nonprofit_event_venue`.
